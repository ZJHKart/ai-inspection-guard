# 智能巡检 · 区域入侵检测（AI Inspection Guard）

浏览器端的"虚拟警戒区"入侵检测系统：载入一张监控画面，自动识别画面中的人员与车辆，判断其是否越过预设警戒区，并把越界目标登记为报警记录。全部推理在本地浏览器内完成，不上传任何图像。

**课程**：《人工智能基础与应用》期末作品
**在线演示**：`（部署后填写 GitHub Pages 链接）`
**技术栈**：原生 HTML / CSS / JavaScript + MediaPipe Tasks Vision（WASM）+ EfficientDet-Lite0（INT8）

---

## 1. 功能

| 模块 | 说明 |
| --- | --- |
| 图像输入 | 拖拽 / 点击上传 / 粘贴剪贴板 / 3 个内置示例场景 |
| 目标检测 | COCO 80 类，默认关注人员、轿车、卡车、客车，可扩展到摩托车、自行车与其他物体 |
| 警戒区 | 画布上直接拖拽移动、八向缩放、一键重绘，坐标以归一化比例保存，与分辨率无关 |
| 入侵判定 | 三种判据：落地点（目标框底边中点）、中心点、目标框重叠面积占比 ≥ 15% |
| 报警记录 | 按置信度排序，含落点坐标、批次、时间；支持导出 CSV（UTF-8 BOM，Excel 直开） |
| 参数联动 | 置信度阈值、类别过滤、判定方式改动后**即时重算**，不需要重新推理 |

## 2. 技术方案

```
图像 → 等比缩放（最长边 1280）→ EfficientDet-Lite0(INT8) 推理
     → 置信度 + 类别双重过滤 → 几何判定（落地点 / 中心点 / 重叠率）
     → 画布绘制 + 报警登记
```

- **检测模型**：EfficientDet-Lite0，COCO 80 类，INT8 量化，约 4.6 MB。选择它是因为体积小、CPU 单帧约 100 ms，纯 WASM 即可运行，不需要 GPU 与后端。
- **判定逻辑**：把警戒区视为一个归一化矩形，取目标框底边中点作为"落地点"，等价于判断"人站在哪里"。相比中心点判据，它能避免远处目标因框体上沿越过边界而误触发。
- **阈值分层**：模型调用时把阈值放宽到 0.10 并缓存原始结果，界面滑杆只在缓存上做二次筛选，因此调参是零成本的，便于观察同一帧在不同阈值下的判定差异。
- **零外部依赖**：模型、WASM 运行时全部放在 `vendor/` 内，不走任何 CDN，内网或弱网环境同样可用。

## 4. 本地运行

浏览器安全策略禁止 `file://` 加载 WASM 与 ES 模块，必须通过 HTTP 访问：

```bash
# 方式一：Python
python -m http.server 8000
# 方式二：Node
npx serve .
```

然后打开 <http://localhost:8000>。首次加载需下载约 23 MB 的 WASM 与模型文件，之后走浏览器缓存。

## 5. 部署

纯静态站点，无构建步骤。推送到 GitHub 仓库后，在 `Settings → Pages` 选择 `main` 分支根目录即可，链接形如 `https://<用户名>.github.io/ai-inspection-guard/`。

## 6. 已知局限

1. **叉车等工程车辆不在 COCO 类别内**，会被识别为 `truck` / `motorcycle` 一类的近似类别；这是预训练模型类别体系的限制，不是阈值问题。
2. 远距离小目标（画面高度占比 < 8%）召回偏低，需要下调阈值或提高输入分辨率。
3. 单一静态图像不包含时序信息，无法区分"路过"与"驻留"，因此报警是一次性判定，不做目标跟踪与去重。
4. INT8 量化在提升速度的同时带来约 1–3 个百分点的精度损失。
