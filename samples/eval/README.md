# 评测集说明（9 张 / 15 个目标）

用于评估"人员与车辆"检出能力的固定小样本集。**不属于演示素材**，全部参与统计，未做挑选剔除。

## 标注协议

1. 只统计本作品默认关注的类别：`person`、`car`、`truck`、`bus`。
2. 叉车、挖掘机等工程车辆不在 COCO 80 类内，**不计入真值**；被模型识别成 `truck` 时计为误报（FP）。
3. 只统计"可辨认出人形／车型"的实例；高度小于画面 5%、或被遮挡到无法判断的不计入。
4. 标注方式：逐张目视计数，与模型输出独立进行。属**计数级标注**，不提供像素级 bbox，因此本评测**不计算 IoU 与 mAP**。

## 匹配规则

同一张图、同一类别：

```
TP = min(检出数, 真值数)
FP = max(0, 检出数 - 真值数)
FN = max(0, 真值数 - 检出数)
```

汇总后 `Precision = TP/(TP+FP)`，`Recall = TP/(TP+FN)`，`F1 = 2PR/(P+R)`。

## 复现方式

在线打开作品 → 点击工具栏"批量检测" → 一次选中 `samples/eval/` 下 9 张图 + `samples/` 下 3 张示例图 → 等待队列跑完 → 点击"导出 CSV"。阈值可在左侧滑杆调整后重跑。

原始逐图结果见 `eval-results.csv`。

## 已知局限

- 样本量小（9 张），只能反映量级，不能替代标准数据集上的 mAP 评测。
- 计数级匹配不区分"框得准不准"，只区分"有没有多检/漏检"。
- 单次标注，未做多人交叉校验。
